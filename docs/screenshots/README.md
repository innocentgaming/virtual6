# BreatheSmart AI — Screenshot Directory

This folder holds screenshots for the BreatheSmart AI documentation and repository showcase.

## Screenshot Slots & Placement Guide

| Target File | Description | Target Dimensions | Section / View |
| :--- | :--- | :--- | :--- |
| `homepage.png` | Main landing hero, particle canvas, and executive overview | 1920×1080 (16:9) | Landing Page / Header |
| `aqi_dashboard.png` | Live AQI centerpiece gauge, PM2.5/PM10 cards, and 24-hr trend chart | 1920×1080 (16:9) | Dashboard Tab |

| `community_hub.png` | Crowdsourced local pollution reports and verified incident upvoting | 1920×1080 (16:9) | Community Tab |

### How to Capture Screenshots
1. Launch the local development server:
   ```bash
   npm run dev
   ```
2. Open `http://localhost:5000` in Google Chrome or your browser.
3. Use Chrome DevTools Device Mode (or full-screen window at 1920×1080).
4. Save the captured images into this directory using the standard file names above.
